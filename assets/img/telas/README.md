# Capturas reais do LiberRotas

Insira nesta pasta capturas de tela em PNG, JPEG ou WebP, com nomes simples. Os seis espaços identificados são: **início, empreendedores, rotas, cupons, perfil e mensagens**.

Depois de inserir os arquivos, configure os caminhos em `assets/js/content.js`, dentro de `telas`.

Não exponha dados pessoais, credenciais, nomes de usuários reais, chaves de acesso ou outros dados sensíveis.
